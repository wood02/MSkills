# Install MSkills

Download the matching platform and architecture from [MSkills Releases](https://github.com/wood02/MSkills/releases). If no package is published, follow the [development instructions](../../../../README.md).

Quit the previous version and back up the complete data directory before installing. Check providers, Skills and sync settings on first launch.

Signing and macOS notarization depend on the particular release. Existing upstream package-manager entries do not install MSkills. Do not delete application data to troubleshoot installation.
