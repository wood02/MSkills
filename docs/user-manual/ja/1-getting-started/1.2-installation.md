# MSkills のインストール

[MSkills Releases](https://github.com/wood02/MSkills/releases) から OS とアーキテクチャに合うパッケージを取得します。未公開の場合は [開発手順](../../../../README_JA.md) からビルドしてください。

旧バージョンを終了し、データディレクトリ全体をバックアップしてからインストールします。初回起動時にプロバイダー、Skills、同期設定を確認してください。

署名と macOS 公証は各リリースの説明に従ってください。上流のパッケージ管理エントリーは MSkills ではありません。
