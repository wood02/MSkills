# MSkills support

Read the [user manual](docs/user-manual/en/README.md) first. For a reproducible problem, open an [issue](https://github.com/wood02/MSkills/issues) with your MSkills version, operating system, expected result and reproduction steps.

Remove API keys, tokens, private URLs and personal data from screenshots and logs. Do not attach a complete database, configuration export or backup to a public issue.

For a data problem, quit the application and back up the complete data directory before attempting recovery. For security reports, follow [SECURITY](SECURITY.md).
